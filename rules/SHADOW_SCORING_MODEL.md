# 空击评分模型 v1.0

> 6维单层评分框架 · 双曲线校准 K=160 · 无对抗环境技术展示评估
>
> 文档性质：评分规则参考档案。供空击视频分析、报告生成等场景直接引用。
>
> 版本：v1.0（2026年5月）

---

## 一、模型设计哲学

### 1.1 评分目标

空击评分的核心判断："这个人在没有压力的情况下，动作能做到什么程度"。

与实战评分的关系：**空击分 ≠ 实战分，但两者有强相关性。** 空击90分的人实战大概率不低于60分；空击40分的人实战大概率不高于50分。空击是基础能力展示，实战是加压测试。

### 1.2 核心原则

1. **无压力基准**：所有维度以"空击/单人训练"表现为准。空击分数天然高于同水平选手的实战分，因为无对手干扰
2. **训练时长为锚**：使用双曲线 `S = 100H/(H+160)` 校准。K=160（低于实战K=200），因为无对抗环境下进步更快
3. **技术展示导向**：评分聚焦于"动作完成度"，不评判战术决策（无对手无从评判）
4. **数据驱动，Pose校验**：帧差法出拳计数 + MediaPipe Pose 骨骼验证，交叉确认

### 1.3 与实战模型的关系

空击评分模型是实战评分模型 v3.0 的**衍生品**，从14维中提取适用维度并重构：

| 实战维度 | 空击映射 | 变化 |
|---------|---------|------|
| 进攻输出 | 出拳输出 | 不含精准命中成分（无目标） |
| 精准命中 | — | ❌ 删除（无对手） |
| 组合能力 | 组合流畅度 | 去掉角度变化（无对手参考） |
| 拳击步伐 | 步伐移动 | 同 |
| 基本功 | 基本功 | 同 |
| 防守意识 | 攻防意识 | 改为"出拳间隙模拟防守动作的密度" |
| 持续耐力 | 协调耐力 | 同，命名更准确（空击中耐力=输出持续性） |
| 距离控制 | — | ❌ 删除（无对手） |
| 临场应变/节奏控制/读对手 | — | ❌ 删除（战术层不适用） |
| 爆发打击/协调速度 | — | ❌ 删除（无对抗下不可靠） |
| 抗击打能力 | — | ❌ 删除（无受击） |

## 二、6维评分框架

### 2.1 维度列表

```
空击能力评分（6维单层，无层级结构）
├── 出拳输出      （17%） — CV量化：出拳/分钟、拳种分布
├── 组合流畅度    （17%） — CV量化：组合占比、多样性
├── 步伐移动      （17%） — Pose量化：无效步占比、步出同步率
├── 基本功        （17%） — Pose量化：拳架保持率、出拳恢复帧数
├── 攻防意识      （17%） — Pose量化：防守动作密度
└── 协调耐力      （15%） — CV量化：输出衰减率
```

### 2.2 权重设计

除耐力降权至15%外，其余5维等权各17%。耐力降权理由：空击环境无法触发真正的体能压力，输出衰减率部分反映的是"专注力衰减"而非纯体能。

## 三、各维度详细定义

### 3.1 出拳输出（17%）

**定义**：单位时间内的出拳量和拳种多样性。空击中的高输出代表训练投入度高、主动性强。

**量化方法**：
- 出拳/分钟 = 总出拳数 ÷ 视频时长（分钟）
- 拳种分布：Jab / Cross / Hook / Uppercut 的占比

**锚点表：**

| 出拳/分钟 | 分数 | 等级 | 典型表现 |
|:--:|:--:|------|---------|
| < 30 | 0-20 | 稀疏 | 长时间停顿，仅1种拳，无节奏感 |
| 30-60 | 20-50 | 基础 | 2-3种拳，有基本节奏但慢 |
| 60-100 | 50-80 | 活跃 | 4种拳切换，出拳连续有节奏变化 |
| 100-150 | 80-100 | 高强度 | 接近实战节奏的输出密度 |

### 3.2 组合流畅度（17%）

**定义**：连续出拳形成组合的能力，包括组合占比和拳种过渡的多样性。

**量化方法**：
- 组合占比 = 属于组合的出拳数 / 总出拳数（2拳以上间隔<1s视为组合）
- 多样性指数 = 组合中不同拳种转换次数 / 组合总数
- 综合指标 = 组合占比 × 0.7 + min(多样性/3.0, 1.0) × 0.3

**锚点表：**

| 综合指标 | 分数 | 等级 | 典型表现 |
|:--:|:--:|------|---------|
| < 0.1 | 0-20 | 无组合 | 全部单拳，打完一拳后停顿 |
| 0.1-0.3 | 20-50 | 初建 | 2拳组合偶见，拳种单一 |
| 0.3-0.5 | 50-80 | 成型 | 3拳组合常见，有头部-身体切换 |
| 0.5-0.7 | 80-100 | 流畅 | 多拳种混合组合，无停顿 |

### 3.3 步伐移动（17%）

**定义**：移动中脚步技术的质量。等同于实战模型的"拳击步伐"维度的无压力版本。

**量化方法**：
- 无效步占比 = 无目的碎步帧数 / 总移动帧数（Pose追踪）
- 步出同步率 = 出拳帧中有脚步配合的比例
- 综合指标 = (1 - 无效步占比) × 0.7 + 步出同步率 × 0.3

**锚点表：**

| 综合指标 | 分数 | 等级 | 典型表现 |
|:--:|:--:|------|---------|
| < 0.4 | 0-20 | 站立不动 | 几乎不移动，或移动时严重失衡 |
| 0.4-0.6 | 20-50 | 基本滑步 | 直进直退，不会变向，步出脱节 |
| 0.6-0.8 | 50-80 | 灵活 | 多方向移动，Pivot自然，步出同步 |
| 0.8-0.95 | 80-100 | 舞步 | 移动流畅如舞蹈，步出完美同步 |

### 3.4 基本功（17%）

**定义**：无压力下技术动作的标准度。等同于实战模型同名维度，但评分锚点更严格（无压力应比有压力做得更好）。

**量化方法**：
- 拳架保持率 = 双手不低于下巴 + 肘部内收的帧占比
- 出拳恢复帧数 = 出拳峰值帧到回到防守位的平均帧数
- 综合指标 = 拳架保持率 × 0.8 + max(0, 1 - 恢复帧数/40) × 0.2

**锚点表：**

| 综合指标 | 分数 | 等级 | 典型表现 |
|:--:|:--:|------|---------|
| < 0.3 | 0-20 | 未成型 | 拳架松散，手垂在腰间，出拳后不回收 |
| 0.3-0.6 | 20-50 | 初步建立 | 基本保持拳架但不稳定，出拳后恢复慢 |
| 0.6-0.85 | 50-80 | 扎实 | 拳架纪律好，出拳后立即回收防守位 |
| 0.85-0.95 | 80-100 | 示范级 | 教科书式动作，无需思考自动保持 |

### 3.5 攻防意识（17%）

**定义**：空击中出拳间隙模拟防守动作的质量和密度。这是空击独有的评估维度——高分选手看起来像在和一个隐形的对手对练。

**量化方法**：
- 防守动作密度 = 非出拳帧中执行防守动作（闪躲/摇臂/格挡/拍挡）的帧占比

**锚点表：**

| 防守密度 | 分数 | 等级 | 典型表现 |
|:--:|:--:|------|---------|
| < 0.05 | 0-20 | 无防守 | 纯粹练拳，没有防守动作 |
| 0.05-0.15 | 20-50 | 偶有防守 | 偶尔闪躲/摇臂，不连续 |
| 0.15-0.3 | 50-80 | 规律防守 | 出拳后有明确的闪躲/格挡回路 |
| 0.3-0.5 | 80-100 | 攻防一体 | 出拳-防守-再出拳无缝循环 |

### 3.6 协调耐力（15%）

**定义**：空击全程保持输出质量和动作标准度的能力。越到后面越累→动作越变形→耐力分越低。

**量化方法**：
- 输出衰减率 = (前半段出拳/分钟 - 后半段出拳/分钟) / 前半段出拳/分钟
- 耐力指数 = 1 - 输出衰减率

**锚点表：**

| 耐力指数 | 分数 | 等级 | 典型表现 |
|:--:|:--:|------|---------|
| < 0.3 | 0-20 | 严重衰减 | 后半段出拳量腰斩，动作明显变形 |
| 0.3-0.6 | 20-50 | 有衰减 | 后半段输出下降明显但不至崩溃 |
| 0.6-0.8 | 50-80 | 基本稳定 | 全程输出接近，轻微下降 |
| 0.8-0.95 | 80-100 | 全程如一 | 从头到尾一个节奏，看不出疲劳 |

## 四、评分校准基准

### 4.1 校准函数

```
S = 100 × H / (H + K)

S: 预期综合分（中位数）
H: 有效训练小时数
K = 160: 空击半饱和参数
```

**K=160 的设计理由：**
- 低于实战 K=200，因为无对抗环境下技能习得曲线更陡（没有对手干扰，进步更快）
- 200h 标准训练 → 中位预期 = 100×200/360 ≈ 55.6分（对战 ≈ 50分）
- 与实战模型保持一致性：公式形式相同，仅参数不同

### 4.2 校准表

| 有效训练量 | 中位分(50th) | 等级描述 |
|--------|:------:|---------|
| 0h | 0 | 零基础 |
| 50h | ~24 | 刚接触 |
| 100h | ~38 | 基本功初成 |
| 150h | ~48 | 入门中段 |
| 200h | **~56** | **入门末期·锚定点** |
| 300h | ~65 | 技术熟练 |
| 500h | ~76 | 资深训练者 |
| 700h | ~81 | 资深上段 |
| 1000h | ~86 | 接近天花板 |

### 4.3 训练质量校准

与实战模型共用同一套质量系数：

| 训练模式 | 质量系数 | 200h有效换算 |
|---------|:---:|:---:|
| 高质量（1v1+固定对练） | 1.3 | 260h → 预期62分 |
| 标准质量（团课+偶尔对练） | 1.0 | 200h → 预期56分 |
| 低质量（自学/无对练） | 0.7 | 140h → 预期47分 |

### 4.4 效率评级

```
效率偏差 = 实际综合分 - 中位预期分
```

| 偏差 | 评级 |
|:---:|:----:|
| < -15 | 显著滞后 |
| -5 ~ -15 | 偏慢 |
| -5 ~ +5 | 正常 |
| +5 ~ +12 | 高效 |
| +12 ~ +20 | 优秀 |
| > +20 | 卓越 |

## 五、评分操作规则

### 5.1 通用规则

1. 锚定训练时长：200h（标准质量）中位预期 ≈ 56分，使用双曲线 `S = 100H/(H+160)` 校准
2. 置信度判定：Pose检测到的事件数 > 30 → 高置信度，10-30 → 中置信度，< 10 → 低置信度
3. 低置信度报告标注"数据不足，初步评估 ±10分"，不宜公开发布
4. 防守动作密度为 0 时，攻防意识维度评分 = 0（明确告知"空击中无防守意识"）
5. 输出衰减率为负（后半段比前半段出拳多）→ 耐力指数 = 1.0（满分，表示体能充裕）
6. 视频时长 < 60s 时降低置信度（样本不足，无法评估耐力衰减）
7. 背景因子不参与评分

### 5.2 与实战模型不可比声明

**空击分和实战分不可直接比较！** 空击56分 ≠ 实战56分。原因：
- 空击无对手压制 → 所有动作完成度天然偏高
- 空击无命中/防守压力 → 评分维度覆盖范围不同
- 空击 K=160，实战 K=200 → 相同训练量下空击预期分更高

**跨模型分数解读指南：**
- 空击分 - 实战分 > 15：典型的"训练场冠军"，压力下表现大幅下滑
- 空击分 - 实战分 < 3：实战能力极强，甚至比训练时更好
- 两者差距 5-12：正常范围

## 六、模型边界声明

### 6.1 空击模型不评估的内容

| 领域 | 为何不评估 |
|------|-----------|
| 战术决策 | 无对手，无从谈起 |
| 命中精准度 | 空击不接触目标 |
| 抗击打能力 | 无受击 |
| 压力下技术保持 | 空击无压力 |
| 实战对抗能力 | 空击表现仅供参考 |

### 6.2 空击模型的适用场景

**最适合：**
- 定期技术评估（每月一次空击录制）
- 训练进步的纵向追踪
- 识别基本动作缺陷
- 无对练搭档时的能力评价

**不应被用于：**
- 预测实战表现
- 取代实战评估
- 作为唯一的能力证明
