## 一、模型设计哲学

### 1.1 排名目标

为拳馆拳击爱好者会员建立一套**激励导向**的跨量级排名体系。核心目标不是纯竞技公平排名（那是BOXREC的职业定位），而是：

- **鼓励持续训练投入**：出勤率高的会员排名不低
- **奖励技术成长**：进步快的会员排名上升
- **跨量级可比**：轻量级和重量级会员在同一榜单上公平竞争
- **月度更新**：形成持续的正反馈循环

### 1.2 与BOXREC职业排名的本质区别

| | BOXREC | 拳神P4P |
|---|---|---|
| 数据源 | 比赛胜负 + 对手质量 | 实战评分 + 出勤率 + 进步速度 + 活跃度 |
| 更新频率 | 赛后即时 | 月度批量 |
| 排名目的 | 竞技公平 | **激励训练投入** |
| 量级处理 | 分量级排名 | 跨量级统排（P4P本质） |
| 最低门槛 | 至少1场职业比赛 | 至少1次视频评估 |

### 1.3 核心原则

1. **技术为主（50%）**：实战能力是P4P的核心，沙袋/空击分仅作为技术分的补充
2. **投入有回报（25%）**：出勤率低但技术好 → 技术分高但总排名会被投入维度拉低
3. **进步被看见（15%）**：从30分涨到50分的会员比一直70分的会员获得更多进步分
4. **活跃有奖励（10%）**：近7天训练频繁的会员享受小幅度加分（与月度训练投入解耦）
5. **会员可退出**：opt_in_ranking = false 的会员不参与排名

## 二、四维排名公式

### 2.1 主公式

```
P4P分 = 技术水平 × 0.50 + 训练投入 × 0.25 + 进步速度 × 0.15 + 活跃度 × 0.10

满分 = 100分
```

### 2.2 各维度定义与计算

#### 维度1：技术水平（权重 50%）

**数据来源**：视频AI评估。支持实战评分、沙袋评分、空击评分。

**计算**：

```
综合评分 = 实战分 × 0.7 + 训练分 × 0.3    （两者都有，训练=沙袋/空击最近一次）
综合评分 = 实战分                              （仅有实战）
综合评分 = 训练分 × 0.5                       （仅有训练，训练分0.5折）
综合评分 = 无数据                              （不参与排名）
```

**训练分折扣（0.5）的理由**：沙袋/空击缺乏对抗压力，不能完全反映独立实战能力。折扣从打靶的0.85进一步降至0.5。

**归一化**：综合评分 / 100 → 0-1区间

**设计理由**：
- 实战为主（0.7）：P4P排名的核心是"谁能打"
- 训练为辅（0.3）：沙袋/空击提供额外的技术参考，同时覆盖无实战评分但有训练评分的会员

#### 维度2：训练投入（权重 25%）

**数据来源**：拳馆出勤记录 CSV（月度汇总）。

**计算**：

```
训练投入分 = 出勤率 × 0.6 + 训练时长分 × 0.4

出勤率 = 当月实际出勤天数 / 当月应出勤天数
训练时长分 = min(当月训练小时数 / 40, 1.0)   （40h/月=满分）
```

**锚点参考**：

| 训练频率 | 出勤率 | 月训练时长 | 训练投入分 |
|---------|:--:|:--:|:--:|
| 每周5天 | 0.95+ | 35-40h | 90+ |
| 每周3-4天 | 0.70-0.85 | 20-30h | 65-80 |
| 每周1-2天 | 0.30-0.55 | 8-15h | 35-55 |
| 偶尔 | < 0.20 | < 5h | < 20 |

**设计理由**：
- 出勤率权重(0.6) > 训练时长权重(0.4)：规律性比单次时间长更有价值
- 40h/月封顶：防止全职训练者在该维度获得不成比例的优势

#### 维度3：进步速度（权重 15%）

**数据来源**：同一拳手的评分历史（至少2次同类型评估）。

**计算**：

```
进步斜率 = (最近一次评分 - 首次评分) / 首次评分距今月数

# v2.5: 不同来源权重不同
实战进步 = 进步斜率 × 1.0           （实战进步全额计入）
训练进步 = 进步斜率 × 0.5           （沙袋/空击进步打5折）

进步速度分 = min(加权进步斜率 / 2.0, 1.0)   （每月有效进步2分=满分）
```

**来源权重设计理由**：

| 来源 | 折扣 | 理由 |
|------|:--:|------|
| 实战评分 | 1.0 | 真实对抗环境，进步直接反映战力 |
| 训练(沙袋/空击) | 0.5 | 无对手压力，进步可替代性强（如"练多了自然熟"不等于能打） |

**评估优先级**：有实战评分 → 用实战数据；无实战但有训练 → 用训练数据×0.5

**分数范围**：0-100（封顶1.0）

**特殊处理**：
- 进步斜率为负（退步）→ 取 0（不惩罚退步）
- 仅有1次评分 → 进步分 = 0（数据不足）
- 首次评分距今 < 1个月 → 按1个月算（防止新会员虚高）

**锚点参考**：

| 进步斜率（分/月） | 进步速度分 | 含义 |
|:--:|:--:|------|
| < 0 | 0 | 退步或持平 |
| 0-0.5 | 0-25 | 缓慢进步 |
| 0.5-1.0 | 25-50 | 正常进步 |
| 1.0-1.5 | 50-75 | 快速进步 |
| 1.5-2.0 | 75-100 | 非常快 |
| > 2.0 | 100 | 突飞猛进（封顶） |

**常数 2.0 的校准待办**：每月进步2分封顶基于初步估计，需积累足够会员数据后校准。

#### 维度4：活跃度（权重 10%）

**数据来源**：出勤记录的近7天统计（v2.5: 缩至7天以区分训练投入的月度量级）。

**计算**：

```
活跃度分 = min(近7天训练次数 / 4, 1.0)   （4次/周=满分，约隔天练）
```

**为什么用7天而非30天**：训练投入（25%）已覆盖月度出勤率+时长。活跃度用7天窗口可独立捕捉"近期热度变化"——如请假两周的会员当月出勤率仍60%，但近7天0次→活跃度归零，提醒回归。

**锚点参考**：

| 近7天训练次数 | 活跃度分 |
|:--:|:--:|
| 0 | 0 |
| 1 | 25 |
| 2 | 50 |
| 3 | 75 |
| 4+ | 100 |

**设计理由**：
- 仅占10%：活跃≠能力强，但"经常来"值得被看见
- 12次/月封顶：防止活跃度稀释其他维度的差异

## 四、排名操作规则

### 4.1 参与门槛

1. 至少1次视频评估（实战、沙袋、空击均可）
2. opt_in_ranking = true
3. 综合评分 ≠ None

不满足任一条件的会员不进入排名列表。

### 4.2 排名周期

- **计算周期**：每月1日自动化计算（或手动触发）
- **数据窗口**：
  - 技术水平：取最近一次评估结果（反映当前状态，不取历史最高）
  - 训练投入：当月（YYYY-MM）出勤记录
  - 进步速度：全部评分历史的斜率
  - 活跃度：近7天训练次数（v2.5: 缩至7天，避免与月度训练投入重叠）

### 4.3 排名输出

**排行榜**：按P4P分降序排列，生成1-N名榜单。同分按综合评分二次排序。

**个人卡片**：每位会员一张P4P卡片，包含四维贡献分解、综合分、排名、月度变化。

### 4.4 数据文件结构

```
gyms/{gym_id}/
├── members.csv              # 会员基础信息
├── attendance/
│   └── attendance_YYYY_MM.csv   # 月度出勤
├── assessments/
│   └── {member_id}_{date}.json  # 评分记录
└── rankings/
    └── YYYY_MM/
        ├── p4p_ranking.json     # 排名结果
        └── cards/
            └── {member_id}_p4p_card.{html,png}  # 个人卡片
```

### 4.5 CSV格式规范

**members.csv**：
```csv
member_id,name,opt_in_ranking
m001,张三,true
```

**attendance_YYYY_MM.csv**：
```csv
member_id,attendance_rate,training_hours,recent_sessions_7d
m001,0.85,36,3
```

**assessments JSON**：
```json
{
    "member_id": "m001",
    "date": "2026-05-27",
    "video_type": "sparring",
    "overall_score": 74.0
}
```

## 五、模型边界声明

### 5.1 本模型不评估的内容

| 领域 | 为何不评估 |
|------|-----------|
| 年龄差异 | P4P排名含进步速度维度，年轻会员天然进步快，但不做专门的年龄加权 |
| 风格克制 | 不同风格的实战效果差异不在排名中体现（需要多场数据后考虑） |
| 教练主观评价 | 不做教练打分，全部基于可量化数据 |
| 社交/影响力 | "拳馆红人"不等于"能打"，排名不反映社交资本 |

### 5.2 已知局限

1. **进步速度对新会员不公平**：首次评分的会员进步速度=0，需要2-3个月后才能在该维度获得正常分数
2. **评估间隔过长影响进步分**：如果两次评估间隔6个月，月均进步斜率会被拉低
3. **出勤率依赖拳馆打卡系统**：如果会员忘记打卡，训练投入分会失真
4. **一次评估样本可靠性低**：单次视频评估受当天状态影响大，建议至少积累2-3次评估后排名更可靠

### 5.3 适用场景

**最适合：**
- 拳馆月度内部排名
- 会员激励（月度进步最快奖、最高出勤奖等）
- 新会员了解自己在拳馆中的位置
- 教练识别训练转化率低的高投入会员

**不应被用于：**
- 预测实战胜负（排名第3不一定打得过排名第5）
- 作为唯一的选材依据
- 跨拳馆排名（不同拳馆评估标准、出勤制度差异大）
